## ▶️ Visualização

1. Baixe ou clone o repositório.
2. Abra a pasta da atividade.
3. Abra `index.html` (Atividade 5) ou `site_musica.html` (Atividade 7) no navegador.

Não é necessário instalar dependências.

## 🎯 Objetivos

Praticar HTML semântico, organização visual, estilização CSS e gerenciamento de arquivos estáticos.
