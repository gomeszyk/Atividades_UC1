# 🧩 Atividade 5 — Tags Semânticas

Exercício de estruturação HTML realizado durante a UC1 do Instituto PROA.

A página contém cabeçalho, navegação superior e lateral, área principal, imagens, seção lateral e rodapé.

**Tecnologias:** HTML5 e CSS3.

## Visualização

Abra `index.html` no navegador. Mantenha `style.css` e as imagens na mesma pasta.

## Conteúdo estudado

Elementos `header`, `nav`, `section`, `aside` e `footer`; estrutura de layout e estilos CSS.
