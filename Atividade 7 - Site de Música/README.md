# 🎸 Atividade 7 — Site de Música

Exercício de HTML e CSS com tema de uma loja fictícia de instrumentos musicais, desenvolvido durante a UC1 do Instituto PROA.

A página apresenta uma introdução, navegação, imagens e cartões demonstrativos de instrumentos.

**Tecnologias:** HTML5 e CSS3.

## Visualização

Abra `site_musica.html` no navegador. Mantenha `site_musica.css` e as imagens no mesmo diretório.

**Objetivo:** praticar organização de seções e criação de elementos visuais com HTML e CSS.
